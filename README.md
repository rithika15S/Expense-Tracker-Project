# Expense-Tracker-Project
Dynamic Expense Tracker Web Application built using HTML, CSS, and JavaScript.

OVERVIEW
           The project allows users to track their income and expenses, view transaction history, and filter transactions by type or date. All data is stored locally in the browser using localStorage, making the app fully dynamic without requiring a backend database.

FEATURES 
 1.User Authentication
 2.Dynamic Login & Register system
 3.Supports multiple users
 4.Session-based access (users must login to access dashboard)

 LOGOUT FUNCTIONALITY 
 ----Dashboard----
1.Displays Total Income, Total Expenses, and Balance
2.Recent transactions displayed in a table
3.Dynamic updates when new transactions are added

----Add Transactions----
1.Add Income or Expense with Type, Amount, Category, and Date
2.Form clears automatically after submission
3.Confirmation popup after adding transaction

---- Transaction History----
1.View all transactions in a table
2.Delete transactions individually
3.Filter transactions by:
4.Income / Expense
5.Specific Date
6.Both Type + Date
7.Displays Total Income and Total Expense based on filtered results

---- UI / Theme----
1.Responsive and modern design
2.Color theme: Skyblue, Navy, Purple, Plum, White
3.Navbar for easy navigation between Dashboard, Add Transaction, History, and Logout


TECHNOLOGIES USED
  1.HTML5
  2.CSS3
  3.JavaScript (ES6)
  4.localStorage (for dynamic data storage)

HOW TO USE; 
 1.Open login.html in your browser.
 2.Register a new user if you don’t have an account.
 3.Login with your credentials.
 4.Navigate through Dashboard, Add Transaction, and History using the navbar.
 5.Add, view, delete, or filter transactions dynamically.
 6.Logout to end the session.

NOTES;
         All data is stored in the browser localStorage. Closing the browser preserves data for the same device and browser.
The project is fully front-end; no server or database required.
